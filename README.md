## 说明

- Android 8.0 及以上
- 使用正式 release 签名
- 数据只保存在手机本地
- 旧调试签名版需要先导出数据、卸载，再安装本版
- 安装完成后，后续版本可以在 App 的「设置 → 应用更新」中检查、下载和安装

安装时 Android 会要求允许「轻记」安装未知应用，并弹出系统安装确认。
